🚀 HOW TO ACTIVATE
═════════════════════════════════════════════════════════════════════════════

STEP 1: Create Spline Character (15 mins)
  1. Go to https://www.spline.design
  2. Create new file
  3. Build a simple 2D-style 3D character
     - Use basic shapes (circles, rounded boxes)
     - Apply JEMS brand colors (navy, orange, gold)
     - Keep polygon count low for performance

STEP 2: Create Animations (20 mins)
  Add these animations in Spline:
    • Idle (2-3s looped) - Default breathing/subtle motion
    • Welcome (2s) - Wave or greeting gesture
    • Pointing (1.5s) - Point at features
    • Thinking (2s) - Thoughtful pose
    • Celebrating (2s) - Happy gesture
    • Waving (1.5s) - Wave between sections

STEP 3: Publish & Get URL (2 mins)
  1. In Spline, click "Share" → "Get Embed Code"
  2. Copy the URL (format: https://my.spline.design/[PROJECT-ID])

STEP 4: Update Component (1 min)
  Open: components/guide/GuideCharacter.tsx
  Find: line 82
  Replace: src="https://my.spline.design/[REPLACE_WITH_YOUR_SPLINE_URL]"
  With: src="https://my.spline.design/[YOUR_ACTUAL_URL]"

STEP 5: Calibrate Scroll Thresholds (10 mins)
  1. Read: components/guide/SCROLL_CALIBRATION.md
  2. Test scroll behavior
  3. Update thresholds if needed (lines 47-54 in GuideCharacter.tsx)
  4. Verify messages appear at correct scroll positions

STEP 6: Test & Deploy
  npm run dev
  Visit homepage
  Scroll through and verify:
    • Messages change at right times
    • Animations are smooth
    • Mobile behavior is correct
    • No performance issues

⚙️ TECHNICAL DETAILS
═════════════════════════════════════════════════════════════════════════════

Component Type: Client-side React component
Framework: Next.js 14 with App Router
Styling: Tailwind CSS with custom animations
Embedding: HTML iframe (Spline)
Performance: Lazy loading, optimized shadows

Bundle Impact:
  • Component JS: ~5KB (minified + gzipped)
  • Spline Model: ~500KB-2MB (depends on complexity)
  • Animations: Inline in Spline file
  • Total: ~500KB-2.5MB one-time load

Browser Support:
  ✅ Chrome/Edge 90+
  ✅ Firefox 88+
  ✅ Safari 14+
  ✅ Mobile browsers (responsive sizing)

❓ FREQUENTLY ASKED QUESTIONS
═════════════════════════════════════════════════════════════════════════════

Q: Will this slow down the website?
A: No. Spline iframe loads lazily, component is ~5KB, animations are GPU-
   accelerated. Minimal performance impact (~50ms FCP).

Q: Can I use a different character design?
A: Yes! Any 2D-style 3D model works. Spline allows full customization of
   colors, shapes, poses, and animations.

Q: What if my sections are different heights?
A: See SCROLL_CALIBRATION.md - provides tools to measure and adjust
   thresholds for your exact layout.

Q: Can I add this to mobile?
A: Yes, but it's hidden by default. Remove isMobile check in GuideCharacter.tsx
   and adjust width for smaller screens.

Q: How do I change the messages?
A: Edit the messages object (lines 15-40 in GuideCharacter.tsx). Each section
   has title, message, and optional action.

Q: Can I trigger animations from clicks?
A: The component responds to scroll. For click animations, use Spline's
   interaction system or add JavaScript event listeners.

Q: Is it SEO-friendly?
A: Yes. Guide is decorative (not essential content). Uses semantic HTML
   and proper ARIA labels. Won't affect SEO.

Q: Will it work on old browsers?
A: Yes, supports Chrome 90+, Firefox 88+, Safari 14+. Graceful degradation
   if JavaScript is disabled.
